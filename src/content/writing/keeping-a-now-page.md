An about page changes slowly. A stream changes too quickly. A now page lives at a useful interval between them.

## A record without a performance

The format works because it is modest. What are you reading? What are you building? What question keeps returning? These are concrete enough to say something, without requiring a polished argument.

## Update by subtraction

When an item is no longer current, remove it. The page does not need to become an archive; Git already remembers. Keeping the visible list short makes each update a small editorial decision.

## Leave a date

The “last updated” line is essential. It turns staleness into context. Even an old now page can be interesting when it is honest about the moment it describes.

Over time, this small habit becomes a map of changing attention—less formal than an essay, more deliberate than a status update.
